# بورتفوليو منار نصر

## الفولدر فيه إيه؟

- `index.html`: الموقع نفسه (كل الكلام والأقسام).
- `works.js`: لستة "نماذج أعمالي". دي اللي هتعدّلي فيها أغلب الوقت.
- `images/`: كل الصور.

---

## أول مرة: ارفعي الموقع على GitHub Pages (مجاني)

1. اعملي حساب على github.com.
2. اضغطي **New repository**، وسمّي الريبو بالظبط كده: `اسم-اليوزر-بتاعك.github.io`، واختاري **Public** وبعدين **Create repository**.
3. اضغطي **uploading an existing file**، واسحبي كل اللي جوه الفولدر ده وحطيهم في الصفحة، وبعدين **Commit changes**.
4. استني دقيقة أو اتنين، وافتحي: `https://اسم-اليوزر-بتاعك.github.io`
5. لو الموقع ما ظهرش: ادخلي **Settings** ثم **Pages**، واختاري **Deploy from a branch** وفرع **main** وفولدر **/ (root)**، وبعدين **Save**.

---

## تعدّلي كلام في الموقع

1. افتحي `index.html` على GitHub، واضغطي على أيقونة القلم (**Edit this file**).
2. كل قسم عليه علامة باسمه زي: `<!-- ==================== خدماتي ==================== -->`
3. غيّري الكلام بس، من غير ما تمسحي العلامات اللي بين < >.
4. اضغطي **Commit changes**، والتعديل يظهر خلال دقيقة.

---

## تضيفي بوست جديد

كل بوست في الموقع عبارة عن صورتين: صورة البوست، وصورة الكابشن.

1. ادخلي فولدر `images` واضغطي **Add file** ثم **Upload files**، وارفعي الصورتين (مثلاً `new1_v.jpg` لصورة البوست و`new1_c.jpg` للكابشن).
2. افتحي `works.js` واضغطي القلم.
3. لاقي السطر `var WORKS = [` وتحته على طول ضيفي سطر زي ده (ومتنسيش الفاصلة في آخره):

```
  {"visual": "images/new1_v.jpg", "caption": "images/new1_c.jpg", "brand": "rossy", "group": "rossy", "categories": "rossy", "link": "https://www.facebook.com/...", "platform": "facebook"},
```

- `categories` و `group`: المجال اللي يظهر فيه البوست: rossy أو samir أو lx أو arena أو misc.
- بوستات يُدنين مكتوبة جوه `index.html` نفسه (الصورة والكابشن كنص)، في قسم "نماذج أعمالي".
- `platform`: facebook أو instagram.
- لو البوست ملوش كابشن (زي الكاروسيل)، شيلي جزء `"caption": ...` خالص.

4. **Commit changes**. البوست هيظهر في أول المجال بتاعه، وعدد الشغل في الفلاتر يتحدّث لوحده.
